# Coworkly API

**Coworkly** — coworking room booking system built as part of a **Java → DevOps → AWS learning roadmap (2025–2027)**.  
Clean monolith first, cloud-ready later.

---

## 🏢 Overview

### 🎯 What it is
Coworkly is a web application for managing coworking-room bookings.  
It serves as my practical project to apply and document each stage of the roadmap (Java → DevOps → Cloud).

### 💡 Project Idea
Coworkly is designed to make it easy to **book and manage coworking rooms**.
- Users can **browse available rooms**, select a **time slot**, and confirm a **booking**.
- Admins can **manage rooms**, monitor **occupancy**, and review **usage metrics**.

Over time, the app will grow to include **authentication**, **payments**, and **monitoring** features.  
It starts as a **Spring Boot monolith** and will gradually evolve into a **cloud-ready, observable, and secure platform**.
